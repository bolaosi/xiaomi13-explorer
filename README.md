# Xiaomi 13 · 精密，由内而外

小米 13 标准版的程序化 3D 拆解探索页。仅使用 Three.js / HTML / CSS / JavaScript；模型、屏幕山景、标识、金属反射和线圈全部由代码生成，无外部模型、图片或运行时外网依赖。无需 npm install 或构建。

## 本地打开

安装 Python 3 后，Windows 双击 `Start-preview.cmd`，自动打开本地网页。保留服务窗口，按 Ctrl+C 停止；端口被其他程序占用时自动选择可用端口。也可在工程目录运行：

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

访问 http://127.0.0.1:8766/ 。请使用 HTTP 服务打开，直接双击 HTML 的 file:// 模式受 ES 模块安全策略限制。Python 只用于本地预览，页面自身没有业务后端。

## 交互

- 点击模型或右侧清单：独立拆解 / 装回部件，查看详情与参数。
- 鼠标拖动 / 单指：旋转；滚轮 / 双指：缩放；右键拖动：平移。
- 拆解滑块：连续调整 10 组部件；支持一键拆解 / 组装。
- 自动演示：依次拆开部件；可暂停，点选部件或拖动滑块时停止演示。
- 透视 / 正面屏幕 / 背面三摄视角、自动旋转、标注开关、全屏。
- E 拆解 / 组装，R 复位，空格演示 / 暂停。输入框、按钮及弹窗内不拦截快捷键。
- 官方参数、模型说明、操作指南弹窗。

## 模型与资料

展示绿色玻璃版小米 13：直边金属中框、圆角玻璃背盖、左上方黑色方形三摄、LEICA 标识、居中打孔的 6.36 英寸直屏、天线分隔、按键和底部接口。10 组部件共 244 个网格：

1. 绿色玻璃背盖
2. 徕卡专业三摄
3. 主板与第二代骁龙 8
4. AMOLED 显示模组
5. 直边金属中框
6. 4500 mAh 电池
7. 无线充电与 NFC 线圈
8. VC 均热板与石墨层
9. 扬声器与 X 轴线性马达
10. USB-C 接口与充电副板

公开规格与外观依据：[小米 13 官方规格](https://www.mi.com/global/product/xiaomi-13/specs/)、[官方产品页面](https://www.mi.com/global/product/xiaomi-13/)。152.8 × 71.5 × 7.98 mm 与 189 g 对应玻璃版，其他材质版本可能不同。IP68 是特定实验室条件下的防护等级，不能理解为日常浸水承诺。

内部芯片封装、主板布线、NFC 天线、线圈、VC 覆盖区域、安装位置及拆解方向为教学近似示意，没有实物测绘或官方 CAD，不可用于维修、装配或工程尺寸核验。锁屏为独立绘制的画面。本项目是独立交互演示，非小米官方产品；相关商标归各自所有者所有。

## 文件与运行环境

- `index.html`：界面、参数、弹窗、加载失败与重试入口。
- `style.css`：深色工作台、浅绿交互和小米橙标记、响应式布局。
- `app.js`：全部几何体、材质与反射、Raycaster、轨道控制、拆解动画。
- `vendor/`：本地 Three.js 0.180.0、OrbitControls、RoundedBoxGeometry 和 MIT LICENSE。
- `DESIGN.md`：设计规范；`Start-preview.*`：本地启动入口。
- `output/`：忽略跟踪的本地验证记录、参考和截图，不参与运行或 GitHub 上传。

支持 import map、ES 模块和 WebGL 2 的现代浏览器。离开视口或切后台时跳过渲染；移动端降低像素比；支持减少动态偏好。只读诊断入口：`window.explorer.getState()`、`window.explorer.projectPart(id)`。

当前小米 13 版本通过 68 项 Chromium 行为检查，包括全部部件拆装、真实模型点击、连续滑块、动画收敛、正反视角、鼠标拖动/滚轮、CDP 单指/双指以及 320–1920px 七种屏宽。另通过全屏进入/退出、模型说明与完整自动演示结束 4 项补充检查。无未捕获 JavaScript 错误或运行时站外请求。触摸检查使用 Chromium CDP，尚未实测真实手机 GPU 与其他浏览器。源码托管于现有仓库，未启用 GitHub Pages；原模型保留在 Git 历史提交中。
