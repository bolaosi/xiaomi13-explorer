# Osmo Action 4 · 精密，由内而外

纯 Three.js / HTML / CSS / JavaScript 的程序化 3D 交互页面。无构建步骤、无运行时外网依赖、无外部模型或图像文件。不需要 npm install。

## 本地打开

Windows 安装 Python 3 后，双击 `Start-preview.cmd`，会打开本地预览；关闭服务窗口或按 Ctrl+C 停止。端口被其他程序占用时自动改用可用端口。也可在当前文件夹执行：

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8766/ 。请通过 HTTP 服务打开，直接双击 HTML 的 file:// 模式会受 ES 模块安全策略限制。

## 交互

- 点击模型或清单部件：独立拆解 / 装回，并显示对应参数。
- 拖动鼠标 / 单指：自由旋转；滚轮 / 双指：缩放；右键拖动：平移。
- 拆解滑块：连续调整全部 10 组部件；一键拆解 / 组装。
- 自动演示：依次拆开部件，可随时暂停；拖动滑块、点选部件会停止演示。
- 正面 / 背面 / 透视、自动旋转、标注开关、全屏。
- 快捷键：E 拆解 / 组装，R 复位，空格播放 / 暂停。输入框、按钮、弹窗内不拦截快捷键。
- 技术规格、模型说明、操作指南弹窗。

## 模型与依据

共 10 组部件，231 个可见网格：保护盖、光学镜头、CMOS、前屏、机身、主板、电池、后屏、接口仓盖、磁吸快拆底座。采用圆角挤出、带孔镜圈、同心镜片、芯片和焊点、线路、物理材质与程序化演播室反射。屏幕山景、文字、机身纹理由 Canvas 生成。

尺寸比例和主要产品参数来自 [DJI 官方规格](https://www.dji.com/cn/osmo-action-4/specs)，外观参照 [官方产品页面](https://www.dji.com/cn/osmo-action-4)。主板布局、芯片型号、内部安装位置、密封件与拆解方向为教学近似示意；没有实物测绘或官方 CAD，不能称作工程级精准复刻，也不能用作维修装配依据。裸机防水参数需在仓盖正确闭合、保护盖拧紧及符合官方条件时理解。

## 文件与技术

- `index.html`：页面、参数、弹窗、加载失败提示。
- `style.css`：深色界面、响应式布局、触屏与减少动态效果支持。
- `app.js`：几何体生成、材质、光照、Raycaster、轨道控制、动画与状态。
- `vendor/`：Three.js 0.180.0 核心、OrbitControls、RoundedBoxGeometry；保留 MIT LICENSE。
- `DESIGN.md`：设计规范。
- `output/`：本地行为检查、截图和验证记录，不是页面运行必需项。

运行环境：支持 ES 模块、import map、WebGL 2 的现代浏览器。页面自适应像素比，离开视口或切入后台时跳过渲染；减少动态模式缩短拆解和视角动画，自动旋转仅由用户主动启动。模型提供诊断用只读 `window.action4.getState()` 与坐标查询 `projectPart()`。

页面已在 Chromium 桌面和移动尺寸检查。65 项行为检查及全屏、模型说明、完整演示结束等 4 项补充检查通过。触摸测试使用 Chromium CDP 输入，不能替代真实手机 GPU 和浏览器兼容性验收。GitHub 仓库用于托管源码，尚未启用 GitHub Pages。
